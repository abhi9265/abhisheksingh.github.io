## Engineering narrative

The portfolio is organized around four engineering case studies rather than a generic technology list:

1. **AI Financial Reconciliation & Finance Intelligence Platform** — multi-tenant ingestion, canonical modeling, deterministic reconciliation, async workers, auditability, and controlled AI review.
2. **Energy Data Platform — Databricks** — lakehouse architecture, metadata-driven ingestion, data quality, historical modeling, and production deployment patterns.
3. **Real-Time Customer Data Platform** — streaming correctness, event-time processing, deduplication, replay safety, and Customer 360 state.
4. **Salesforce → Databricks Deal Automation** — state machines, idempotent API workflows, retries, explicit unknown outcomes, and operational recovery.

Each project is intended to answer four senior-engineering questions: **What problem was being solved? Why was the architecture chosen? What happens when it fails? How was the result validated?**
